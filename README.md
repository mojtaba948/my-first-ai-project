My First AI Project: Cat vs Dog Classification

Final project for the Building AI course

Summary

This project demonstrates binary classification using a simple logistic regression model. It uses a small synthetic dataset with three numerical features (height, weight, and length) to distinguish between cats and dogs. It is an educational project, not an image recognition system.

Background

Cats and dogs are two of the most common household pets. Distinguishing between them is an interesting example of a binary classification problem in artificial intelligence.

The goal of this project is to understand how a simple AI model can use numerical information to make a prediction.

The main motivations for this project are:

* Learning the basic concepts of artificial intelligence and machine learning.
* Understanding how binary classification works.
* Exploring how numerical features can help a model make predictions.
* Practicing the implementation of a simple machine learning algorithm using Python.

How is it used?

The project is designed as a simple educational demonstration.

To use the program:

1. Make sure Python 3 is installed on your computer.
2. Download or clone this GitHub repository.
3. Open a terminal or command prompt in the project folder.
4. Run the Python script:

python cat_dog_ai.py

The program uses numerical features such as height, weight, and length to demonstrate how a model can distinguish between two classes: cats and dogs.

The intended users are beginners, students, and anyone interested in learning the basic principles of artificial intelligence.

This program does not analyze photographs or identify real animals.

Data sources and AI methods

The project uses a small synthetic dataset created for educational purposes. The dataset contains six example observations with three numerical features:

* Height
* Weight
* Length

The AI method used is logistic regression, a supervised machine learning algorithm for binary classification.

A sigmoid function is used to convert the model's output into a value between 0 and 1. The model uses a basic gradient descent approach to adjust its parameters during training.

The project is implemented in Python.

No external dataset or real animal photographs are used.

Challenges

This project has several limitations:

* The dataset is very small and contains only six examples.
* The data is synthetic and does not represent the full variety of real cats and dogs.
* The model uses only three numerical features.
* The model cannot recognize animals from images.
* Its predictions should not be considered reliable for real-world animal classification.

The project is intended for learning and experimentation, not for practical or professional use.

An important ethical consideration is that AI predictions should not be trusted without considering the quality and limitations of the data used to train the model.

What next?
